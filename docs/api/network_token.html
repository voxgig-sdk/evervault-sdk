POST /payments/network-tokens/{network_token_id}/simulate

Operation ID: simulateNetworkTokenUpdate.

Authentication: basic token (ApiKey).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | network_token_id | path | string | Yes | The id of the Network Token |

Request body

application/json

Property Type Required Description
updateType enum: new-token-status, new-card-expiry-and-last-four, new-token-expiry-and-number No The type of update to simulate.

Responses

200: Returns the updated Network Token object

application/json

Property Type Required Description
card object Yes The details of the underlying encrypted card.
card.brand enum: visa, mastercard, american-express No The card brand associated with the payment card.
card.expiry object No The expiry details of the card.
card.expiry.month string No The month of the card's expiry date, in MM format (for example 12 for December)
card.expiry.year string No The year of the card's expiry date, in YY format (for example 26 for 2026)
card.lastFour string No The last four digits of the card number.
createdAt integer (int64) Yes The exact time, in epoch milliseconds, when this Network Token was created.
expiry object Yes The expiry details of the Network Token.
expiry.month string No The month of the Network Token's expiry date, in MM format (for example 12 for December)
expiry.year string No The year of the Network Token's expiry date, in YY format (for example 26 for 2026)
id string Yes A unique identifier representing a specific Network Token.
merchant string Yes The unique identifier of the Merchant associated with this Network Token.
number string Yes The unique number of the Network Token.
paymentAccountReference string No The unique identifier of the Payment Account associated with this Network Token.
status enum: active, inactive, blocked, provisioning, suspended, deleted, ... Yes The status of the Network Token. Active means the token is valid and can be used for payments. Inactive means the token exists but is not currently active. Blocked and provisioning are reserved for future use. Suspended means the token is temporarily unusable but may be reactivated by the issuer or transition to deleted. Deleted is a terminal state where the token is permanently removed and a new credential must be obtained. Expired means the token has passed its expiration date and should not be used for transactions.
tokenRequestorIdentifier string Yes The identifier of the Token Requestor (TRID) that requested the Network Token.
tokenServiceProvider enum: mdes, vts, aets Yes The Token Service Provider (TSP) that issued the Network Token.
updatedAt integer (int64) No The exact time, in epoch milliseconds, when this Network Token was last updated.
