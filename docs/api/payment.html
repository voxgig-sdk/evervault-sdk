GET /payments/merchants

Operation ID: listMerchants.

Authentication: basic token (ApiKey).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | page | query | integer | No | The page number to retrieve. | | pageSize | query | integer | No | The number of Merchants to retrieve per page (default is 50). | | q | query | string | No | Filter the Merchants by name. |

Responses

200: Returns a list of Merchant objects

application/json

Property Type Required Description
data array of object Yes
data[].applePay object No The Merchant's Apple Pay configuration.
data[].applePay.domains array of object No The domains the Merchant has enrolled with Apple Pay and the status of the enrollment.
data[].applePay.domains[].domain string No The top-level domain name of the Merchant's website.
data[].applePay.domains[].status enum: active, pending, failed No The current status of the Merchant's Apple Pay enrollment for the specified domain. active means the Merchant is fully enrolled and can accept Apple Pay payments on the domain.
data[].business object No The business details of the Merchant.
data[].business.address object No The physical address of the Merchant's principal place of business.
data[].business.address.city string Yes The city where the address is located.
data[].business.address.country string (iso-3166-1-alpha-2) Yes The country where the address is located.
data[].business.address.line1 string Yes The first line of the address.
data[].business.address.line2 string No The second line of the address.
data[].business.address.postalCode string Yes The postal code of the address.
data[].business.address.state string (iso-3166-2-subdivision) No The state or province code. Required when country is us, ca, or au.
data[].business.legalName string No The legal name under which the Merchant's business is registered.
data[].categoryCode string No The 4-digit Merchant Category Code (MCC).
data[].createdAt integer (int64) Yes The exact time, in epoch milliseconds, when this Merchant was created.
data[].id string Yes A unique identifier assigned to each Merchant.
data[].name string Yes The official name of the Merchant as recognized in transactions and communications. This name is used for display purposes and may be the company's trade name or a derived nickname.
data[].networkTokens object No The Merchant's Network Token configuration.
data[].networkTokens.enrolment array of object No An array detailing the Merchant's enrollment status for network token issuance across different card brands.
data[].networkTokens.enrolment[].cardBrand enum: visa, mastercard, american-express, discover, diners-club, jcb, ... No The card brand (for example, Visa, Mastercard, American Express) for which the enrollment status is being described. Currently, Network Tokens is only supported for Visa, Mastercard and American Express.
data[].networkTokens.enrolment[].status enum: active, inactive No The current stage of the Merchant's enrolment process for network token issuance with the specified card brand.
data[].networkTokens.enrolment[].tokenRequestorIdentifier string,null No The unique Token Requestor Identifier (TRID) associated with the Merchant for the specific card brand. This identifier is used when creating Network Tokens for the Merchant.
data[].shortName string No A shorter version of the Merchant's name. When creating a 3D Secure session that references this Merchant by ID, shortName is used in place of name if name exceeds the 40-character limit imposed by the 3D Secure specification.
data[].updatedAt integer (int64) No The exact time, in epoch milliseconds, when this Merchant was last updated.
data[].website string Yes The official website URL of the Merchant. The domain must use a valid IANA top-level domain. See https://data.iana.org/TLD/tlds-alpha-by-domain.txt
nextPage integer,null Yes The next page number to retrieve. If there are no additional Merchants, this will be null.
pageSize integer Yes The number of Merchants retrieved per page.
total integer Yes The total count of all Merchants, after any filters.

GET /payments/acquirers

Operation ID: listAcquirers.

Authentication: basic token (ApiKey).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | page | query | integer | No | The page number to retrieve. | | pageSize | query | integer | No | The number of Acquirers to retrieve per page. The default is 50, which is also the maximum. |

Responses

200: Returns a list of Acquirer objects

application/json

Property Type Required Description
data array of object Yes
data[].configurations array of object Yes The acquirer configuration settings.
data[].configurations[].acquirerMerchantIdentifier string Yes The merchant identifier the configuration is associated with.
data[].configurations[].bin string Yes The Bank Identification Number (BIN) of the Acquirer. Must be 6 to 11 digits.
data[].configurations[].country string (iso-3166-1-alpha-2) Yes The country of the acquirer configuration, used when creating 3DS sessions.
data[].configurations[].network enum: visa, mastercard, american-express, discover Yes The card network of the Acquirer. discover covers Discover, Diners Club, and JCB (US only).
data[].configurations[].state string Yes
data[].default boolean Yes
data[].description string No The description of the acquirer configuration.
data[].id string Yes The unique identifier of the acquirer configuration.
data[].name string Yes The name of the acquirer configuration.
nextPage integer,null Yes The next page number to retrieve. If there are no additional Acquirers, this will be null.
pageSize integer Yes The number of Acquirers retrieved per page.
total integer Yes The total count of all Acquirers.
