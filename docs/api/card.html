Property Type Required Description

card.expiry.month string No The card expiry month
card.expiry.year string No The card expiry year

cardholder object No Details about the cardholder that the name verification (ANI) is for. Required if the cardholder extension is requested.
cardholder.firstName string No The first name of the cardholder
cardholder.lastName string No The last name of the cardholder
extensions array of enum: capabilities, cvv, cardholder, address No The extensions to the card insight request.
