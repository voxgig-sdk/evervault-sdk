create

POST /functions/{function_name}/runs

Operation ID: createFunctionRun.

Authentication: basic token (ApiKey) or bearer token (TokenAuth).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | function_name | path | string | Yes | The name of the Function to be executed. |

Request body

application/json

Property Type Required Description
async boolean No If you want your Function to run asynchronously and notify a callback URL, this can be set to true and the API will queue your Function run and return a 202 response code.
payload object Yes The data payload that the Function will use during its execution. Any encrypted values will be decrypted before being passed to the function.

Responses

200: The Function run has completed

Property Type Required Description

id string No A unique identifier representing this specific Function execution instance.
result object No This field represents the output returned by the Function. This is provided only when the Function execution status is 'success'.
status enum: success, failure, scheduled No The outcome of the Function execution.
