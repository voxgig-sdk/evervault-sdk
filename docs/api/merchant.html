create

POST /payments/merchants

Operation ID: createMerchant.

Authentication: basic token (ApiKey).

Request body

application/json

Property Type Required Description
applePay object No The Merchant's Apple Pay configuration.
applePay.domains array of string No The domains the Merchant wants registered with Apple Pay. Only the domain name is required, without the protocol or path. For example, example.com is a valid domain, but https://example.com is not.
business object Yes The business details of the Merchant.
business.address object Yes The physical address of the Merchant's principal place of business.
business.address.city string Yes The city where the address is located.
business.address.country string (iso-3166-1-alpha-2) Yes The country where the address is located.
business.address.line1 string Yes The first line of the address.
business.address.line2 string No The second line of the address.
business.address.postalCode string Yes The postal code of the address.
business.address.state string (iso-3166-2-subdivision) No The state or province code. Required when country is us, ca, or au.
business.legalName string Yes The legal name under which the Merchant's business is registered.
categoryCode string Yes The 4-digit Merchant Category Code (MCC).
name string Yes The official name of the Merchant as recognized in transactions and communications. This name is used for display purposes and may be the company's trade name or a derived nickname.
networkTokens object No The Merchant's Network Tokens configuration. This field should only be populated if the Merchant has already been enrolled in one of the Card Network programs and can use an existing Token Requestor ID (TRID).
networkTokens.enrolment array of object No
networkTokens.enrolment[].cardBrand string No The Card Brand for which the configuration belongs to.
networkTokens.enrolment[].tokenRequestorIdentifier string,null No The existing Token Requestor ID assigned by the Card Brand.
shortName string No A shorter version of the Merchant's name. Optional. When creating a 3D Secure session that references this Merchant by ID, shortName is used in place of name if name exceeds the 40-character limit imposed by the 3D Secure specification.
website string Yes The official website URL of the Merchant. The domain must use a valid IANA top-level domain. See https://data.iana.org/TLD/tlds-alpha-by-domain.txt
