Fields

Field Type Required Description
number string Yes The card number for which the BIN lookup is being requested.

create

POST /payments/bin-lookups

Operation ID: createBinLookup.

Authentication: basic token (ApiKey).

Request body

application/json

Property Type Required Description
number string Yes The card number for which the BIN lookup is being requested. It can be a plaintext Card number (FPAN) / Network Token number (DPAN), an encrypted Card number / Network Token number or simply just a BIN (6-10 first digits of a Card Number) for range lookup.

Responses

201: Returns BIN details for the provided card number
