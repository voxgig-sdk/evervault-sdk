Set up the client

This setup fragment reads credentials from the environment. Use the API operation reference to supply input for each call.

import { EvervaultSDK } from '@voxgig-sdk/evervault-sdk'

const client = new EvervaultSDK({ apikey: process.env.EVERVAULT_APIKEY })
