Tools

evervault_list

List records for an entity.

{
  "type": "object",
  "required": [
    "entity"
  ],
  "properties": {
    "entity": {
      "type": "string",
      "description": "acquirer | bin_lookup | card | card_art | client_side_token | core | custom_domain | function_run | merchant | network_token | network_token_cryptogram | payment | relay | three_ds_session | webhook | webhook_endpoint"
    },
    "query": {
      "type": "object",
      "description": "Optional match fields for the selected entity."
    }
  }
}

Supported entities: core, payment, webhook.

evervault_load

Load one record for an entity.

{
  "type": "object",
  "required": [
    "entity"
  ],
  "properties": {
    "entity": {
      "type": "string",
      "description": "acquirer | bin_lookup | card | card_art | client_side_token | core | custom_domain | function_run | merchant | network_token | network_token_cryptogram | payment | relay | three_ds_session | webhook | webhook_endpoint"
    },
    "query": {
      "type": "object",
      "description": "Optional match fields for the selected entity."
    }
  }
}

Supported entities: acquirer, card, card_art, custom_domain, merchant, network_token, relay, three_ds_session, webhook_endpoint.
